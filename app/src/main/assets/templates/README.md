# Card templates

Place grayscale/PNG templates here for OpenCV matching:

- `rank_ace.png` … `rank_king.png` (or `rank_<enum lowercase>.png`)
- `suit_hearts.png`, `suit_diamonds.png`, `suit_clubs.png`, `suit_spades.png`
- `empty_slot.png`
- `face_down.png`

Crop from your Solitaire Smash screenshots at a consistent badge size.
Recognition works in degraded mode without these files, but live accuracy needs them.
